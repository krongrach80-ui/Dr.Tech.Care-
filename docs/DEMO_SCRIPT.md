# บทสาธิตการใช้งานระบบ Dr.Tech.Care (Demonstration Walkthrough Script)
**เป้าหมาย:** สำหรับผู้บริหารโรงพยาบาลและนักกายภาพบำบัด

---

## ฉากที่ 1: หน้าแรกตู้ Kiosk และการกดค้างปุ่มบุคลากร (Kiosk Shell & Staff Long-Press)
1. เปิดหน้าแรก `https://dr-tech-care.vercel.app/`
2. แสดงผลหน้าจอแนวตั้ง 9:16 โทนสีเขียวมิ้นต์-ฟ้า (Aurora Mint-Cyan) พร้อมตัวอักษรภาษาไทยขนาดใหญ่ สบายตาสำหรับผู้สูงอายุ
3. สังเกตแถบด้านบน: มีนาฬิกา วันที่ พ.ศ. และสถานะระบบออนไลน์
4. **ทดสอบความปลอดภัย:** ลองแตะปุ่ม "สำหรับบุคลากร" ครั้งเดียวแบบเร็ว -> ระบบไม่เปิดหน้าเจ้าหน้าที่ (ป้องกันผู้ป่วยกดผิด)
5. **กดค้าง 1.5 วินาที:** จะมีหลอดเกจแถบสีเขียววิ่งเต็ม 100% แล้วนำทางเข้าสู่พอร์ทัลเจ้าหน้าที่อย่างราบรื่น

## ฉากที่ 2: การเข้าสู่ระบบด้วยใบหน้าแบบ 3 ขั้นตอน (3-Step Face Liveness Login)
1. แตะปุ่มใหญ่สีเขียว "สแกนใบหน้าเพื่อเข้าสู่ระบบ"
2. แสดงหน้าข้อความยินยอม PDPA (ไม่ติ๊กถูกไว้ล่วงหน้า) พร้อมปุ่มยืนยัน
3. กล้องเปิดขึ้นมาพร้อมกรอบวงรีสีเขียวและเสียงภาษาไทยแนะนำ
   - **ขั้นที่ 1:** มองตรงที่กล้อง
   - **ขั้นที่ 2:** หันศีรษะไปทางซ้ายช้า ๆ
   - **ขั้นที่ 3:** หันศีรษะไปทางขวาช้า ๆ
4. เมื่อครบ 3 มุม เวกเตอร์ตัวเลข 128 มิติจะถูกส่งไปเทียบเคียง และแสดงผลยืนยันตัวตนสำเร็จ

## ฉากที่ 3: แดชบอร์ดคนไข้และตารางการฝึกประจำวัน (Patient Dashboard & Checklist)
1. เข้าสู่หน้าแดชบอร์ดคนไข้ ต้อนรับ "คุณ สมพงษ์ สุขใจ"
2. ตารางภารกิจประจำวัน:
   - ท่าที่ 1: กายภาพบำบัดยกแขน (Shoulder Abduction)
   - ท่าที่ 2: มินิเกมฝึกสมองประจำวัน (Daily Brain Training)
3. เมื่อทำครบ: แถบสถานะติ๊กถูกสีเขียว นำทางไปสู่หน้าสรุปผล และมีปุ่มออกจากระบบพร้อมตัวจับเวลานับถอยหลัง 45 วินาที

## ฉากที่ 4: การแจ้งอาการไม่พึงประสงค์และระบบเตือนฉุกเฉิน (Red Flag Emergency)
1. แตะเมนู "แจ้งอาการ" ที่แถบด้านล่าง
2. แสดงหน้าต่างบันทึกตำแหน่งอาการและคะแนนความเจ็บปวด (Pain Score 0-10)
3. ลองติ๊กสัญญาณอันตราย (เช่น เจ็บแน่นหน้าอกร้าวไปกราม)
4. ระบบจะดีดเข้าสู่หน้าจอฉุกเฉินสีแดงทันที พร้อมปุ่มโทรด่วน 1669 และส่งการแจ้งเตือน Realtime ไปยังนักกายภาพบำบัด
