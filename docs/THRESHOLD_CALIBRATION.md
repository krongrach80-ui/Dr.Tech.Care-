# คู่มือการปรับจูนเกณฑ์ชีวมิติใบหน้า (Biometric Threshold Calibration Guide)
**โครงการ: Dr.Tech.Care**

---

## 1. สูตรคณิตศาสตร์และเกณฑ์การวัด (Distance Metrics)
ระบบใช้เวกเตอร์ 128 มิติ (`vector(128)`) ที่ได้จากโมเดล Deep Metric Learning โดยใช้การวัดระยะห่างแบบ Euclidean (L2 Distance) และ Cosine Distance:

$$d(u, v) = \sqrt{\sum_{i=1}^{128} (u_i - v_i)^2}$$

หรือ Cosine Distance:
$$D_C(u, v) = 1 - \frac{u \cdot v}{\|u\|_2 \|v\|_2}$$

## 2. พารามิเตอร์เกณฑ์มาตรฐาน (Operational Thresholds)
- **`matchThreshold = 0.40`:** หากระยะห่าง $\le 0.40$ ถือว่าใบหน้ามีความคล้ายคลึงเพียงพอที่จะจับคู่
- **`ambiguousDelta = 0.05`:** หากอันดับ 1 และอันดับ 2 มีผลต่างระยะห่างน้อยกว่า $0.05$ (เช่น 0.32 กับ 0.34) ระบบจะตัดสินเป็น `ambiguous` และไม่อนุญาตให้เข้าสู่ระบบอัตโนมัติ เพื่อป้องกัน False Acceptance

## 3. ความสัมพันธ์ระหว่าง FAR (False Acceptance Rate) และ FRR (False Rejection Rate)
- **หากปรับเกณฑ์ต่ำลง (เช่น 0.35):**
  - **ข้อดี:** FAR ลดลงอย่างมาก (ความปลอดภัยสูงขึ้น โอกาสที่คนอื่นจะปลอมเป็นเราเข้าใกล้ศูนย์)
  - **ข้อเสีย:** FRR สูงขึ้น (ผู้สูงอายุที่แสงเปลี่ยนหรือหน้ามีรอยย่นอาจต้องสแกนซ้ำบ่อยขึ้น)
- **หากปรับเกณฑ์สูงขึ้น (เช่น 0.48):**
  - **ข้อดี:** FRR ต่ำลง (สแกนผ่านง่ายขึ้นในสภาพแสงน้อย)
  - **ข้อเสีย:** FAR สูงขึ้น มีความเสี่ยงที่จะเกิด False Match

## 4. ขั้นตอนการ Calibrate ด้วยชุดภาพทางคลินิกจริง (Clinical Dataset Protocol)
1. รวบรวมชุดภาพถ่ายใบหน้ามุมตรงและหันซ้าย-ขวาของผู้รับบริการที่ลงนามยินยอมตามแบบฟอร์ม PDPA
2. วางชุดภาพในไดเรกทอรี `tests/data/clinical_faces/`
3. รันสคริปต์คำนวณกราฟ ROC (Receiver Operating Characteristic) เพื่อหาจุด EER (Equal Error Rate) ที่เหมาะสมที่สุดสำหรับประชากรผู้สูงอายุไทย
