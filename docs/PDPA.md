# นโยบายคุ้มครองข้อมูลส่วนบุคคลและข้อมูลชีวมิติ (PDPA Compliance)
**โครงการ: Dr.Tech.Care ตู้ Kiosk กายภาพบำบัดอัจฉริยะ**
**เวอร์ชันเอกสาร:** 1.0 (ตุลาคม 2569)

---

## 1. ขอบเขตและสถานะทางกฎหมาย
ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) มาตรา 26 ข้อมูลชีวมิติ (Biometric Data) รวมถึงข้อมูลภาพจำลองใบหน้า จัดเป็น **ข้อมูลส่วนบุคคลที่มีความอ่อนไหวเป็นพิเศษ (Sensitive Personal Data)** ระบบ Dr.Tech.Care ยึดถือกฎระเบียบเคร่งครัดสูงสุดในการคุ้มครองสิทธิของผู้รับบริการ

## 2. หลักการจัดเก็บข้อมูลชีวมิติแบบ Zero-Image Retention
1. **ห้ามจัดเก็บภาพถ่ายใบหน้าจริงโดยเด็ดขาด (No Raw Image Storage):**
   - เฟรมภาพจากกล้อง `getUserMedia` จะถูกประมวลผลบนหน่วยความจำแรม (RAM) ของเบราว์เซอร์ผ่าน WebAssembly (WASM) ในเครื่องเท่านั้น
   - ไม่มีการบันทึกภาพนิ่ง ภาพเคลื่อนไหว หรือไฟล์ภาพลงใน LocalStorage, SessionStorage, IndexedDB, Cache API หรือเซิร์ฟเวอร์
2. **การแปลงข้อมูลเป็นเวกเตอร์คณิตศาสตร์ทางเดียว (One-Way 128-d Vector Embedding):**
   - โครงหน้าจะถูกแปลงเป็นค่าตัวเลขทศนิยม Float32 จำนวน 128 มิติ (`vector(128)`)
   - ไม่สามารถย้อนกลับ (Irreversible) เพื่อประกอบสร้างเป็นภาพใบหน้ามนุษย์จริงได้ (ป้องกัน Re-identification และ Inversion Attack)

## 3. กลไกการขอความยินยอม (Affirmative Consent)
- **ไม่ติ๊กถูกไว้ล่วงหน้า (No Pre-checked Checkboxes):** ผู้ใช้ต้องกดปุ่มยินยอมด้วยตนเองเท่านั้น
- **การบันทึกหลักฐานความยินยอม:** จัดเก็บเวอร์ชันข้อความ (`text_version`) และรหัสแฮช SHA-256 (`text_sha256`) ของข้อความยินยอมลงในตาราง `public.face_consents`

## 4. สิทธิในการถอนความยินยอมและการลบข้อมูล (Right to Withdraw & Erasure)
- ผู้รับบริการสามารถขอเพิกถอนความยินยอมได้ตลอดเวลาผ่านเจ้าหน้าที่หรือหน้าตู้
- เมื่อถอนความยินยอม: เวกเตอร์ในตาราง `public.face_embeddings` จะถูกลบถาวร (Hard Delete) พร้อมบันทึกใน Audit Log ทันที
